Meu Primeiro Exercício de Front-End

Primeiros passos na criação de páginas para a web

Sobre a disciplina

A disciplina de Front-End apresenta as tecnologias usadas para criar a parte visual e interativa de sites e sistemas. Durante as aulas, vamos aprender HTML, CSS, JavaScript e outras ferramentas importantes para o desenvolvimento web.

Objetivo deste exercício

Este exercício tem como objetivo praticar a estrutura básica de uma página HTML, utilizando títulos, parágrafos, seções e informações organizadas de forma simples.
